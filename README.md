# ReadingPaper

一个用于整理论文阅读笔记的个人网页论文库。

ReadingPaper 以论文为单位保存阅读记录，将独立的 HTML 笔记组织成可浏览、可检索的静态网站，方便回顾论文、追踪阅读进度，以及积累对研究问题、写作方式和方法实现的理解。

## 阅读内容

每篇论文有独立的总览页，阅读笔记分为三个阶段，可按需要逐步补充：

- **第一遍初读**：梳理研究问题、已有工作的不足、核心思路、方法轮廓和实验结论，建立对整篇论文的理解。
- **第二遍写作精读**：分析摘要、引言和结论的组织方式，理解作者如何引出问题、衔接论证并表达贡献。
- **方法与代码阅读**：结合框架图、公式和源码，理解方法的具体实现及其与论文描述的对应关系。

阅读页保留笔记中的图表、原文定位与参考链接，便于在总结和来源之间来回核对。

## 浏览论文库

下载仓库后，用浏览器打开 [index.html](index.html) 即可浏览。首页支持关键词搜索、发表来源与阅读阶段筛选，以及按阅读日期或发表年份排序。

网站采用 HTML、CSS 和 JavaScript，无需后端服务；也可通过 GitHub Pages 托管。

从 [研究地图](research-map.html) 可以浏览任务与方法树、技术挑战与 insight 树，以及按五个分支展开的单篇论文解析。解析中的笔记转述、阅读者归纳和待核验内容分别标注；点击证据可返回原阅读位置。数据格式与维护规则见 [研究地图说明](research-map/README.md)。

## 内容维护

阅读笔记以 HTML 为主，也支持 Markdown。所有论文统一存放在 `papers/` 下。新增内容时，将笔记放入 `papers/论文名-年份/`，在 `papers.json` 中登记论文信息和阅读阶段，再通过构建脚本更新首页与总览页面。

目录管理、页面生成、检查与发布步骤见 [网站维护与发布](docs/site-workflow.md)。
