概率标签、入选掩码和学习权重，是同一种“置信度”吗？

SnowRemovalNet · 2026-11-21 · 独立专题

不是新论文，也不是新增阅读阶段。重新取得20页出版PDF，重点复核公式、算法及主对照。未读代码、未复现。

原论文初读 · 专题目录 · 离线伪标签使用卡

答：不是。 标签 yᵢ 是离线雪类软目标，掩码 Mᵢ 决定是否计入训练损失，权重 wᵢ 分配入选点的相对影响。离 0.5 的距离是作者采用的可靠性代理，不是经校准的标签正确概率。高权重也不保证实际梯度更大。

1. 同一个标签，在三个地方承担不同职责

作者表述先前工作 [11] 的 ASDR 通过自适应强度候选与 DSOR 生成硬伪标签，再由 C-GLP 利用邻域信息给出软标签。本文用其固定离线结果：接近0倾向非雪，接近1倾向雪，接近0.5表示模糊。推理输出 pᵢ = σ(xᵢ)，不再运行标签器；预测 pᵢ ≥ 0.5 才作删点判定。[Sec. 4.2，PDF p.5；Sec. 4.6，p.9]

教什么，Eq. (1)： BCEᵢ = −[yᵢ log(pᵢ) + (1 − yᵢ) log(1 − pᵢ)]。yᵢ = 0.05 是强非雪目标，不是只有5%标签置信度。

何时纳入，Eq. (4)： 第一段仅选 yᵢ ≤ 0.1 或 yᵢ ≥ 0.9，第二段扩至 yᵢ ≤ 0.3 或 yᵢ ≥ 0.7，最后一段不设门槛。Mᵢ = 0 才让该点不进入直接损失；去掉门槛不意味着每点在每次随机抽样中都出现。

纳入后分多少，Eqs. (2)–(3)： wᵢ = max(0.5, 2 × |yᵢ − 0.5|)，L = Σᵢ (Mᵢ wᵢ BCEᵢ) / Σᵢ (Mᵢ wᵢ)。0.5 是归一化前的权重下限，不是“贡献全体梯度的50%”。

2. 权重有平台，梯度还看当前预测

阅读者推导 固定一个小批量及其训练阶段，若 S = Σⱼ (Mⱼ wⱼ) > 0，离线 yᵢ、Mᵢ、wᵢ 和 S 对当前 logit xᵢ 是常数。由 Eq. (1) 对 logit 求导得 pᵢ − yᵢ，再乘 Eq. (3) 的点系数：

∂L/∂xᵢ = (Mᵢ wᵢ / S) × (pᵢ − yᵢ)

平台区： 0.25 ≤ yᵢ ≤ 0.75 时 wᵢ 恒为 0.5。比如 y = 0.30 和 y = 0.50 的权重一样；第二阶段靠掩码区别是否入选，第三阶段两者都入选且权重相同，但各自软目标不同。

反例（构造，不是实测）： 第三阶段同一小批里，y = 0.95、p = 0.94 时梯度幅值为 0.9 × 0.01 / S = 0.009 / S；y = 0.50、p = 0.90 时为 0.5 × 0.40 / S = 0.20 / S。后一项权重更低，logit 梯度反而更大。网络参数梯度还要乘各 logit 到参数的导数再汇总，不能从单点幅值直接推算参数更新。以上是从原式展开，不是作者实验结论。[PDF p.5]

3. 训练时筛点，验证时不筛

直接观察Algorithm 1 第4–7行在训练小批用 Eq. (3)；第8行计算验证集中 wᵢ BCEᵢ 的均值，不用课程掩码；第9–10行只在第三阶段用更低验证损失更新 checkpoint。训练写作除以有效权重和，验证写作加权项的均值，未查代码不声称两者实现完全相同。Table 1 分21训练、9验证，验证仍使用概率标签，不是独立人工真值。论文未交代空掩码小批的处理。[Algorithm 1，p.6；Table 1，p.10]

4. 消融支持成套训练，不能分别归因

直接观察CADC/WADS 主表的完整组 F1 为 98.10%/97.23%，硬标签且同时取消课程和加权为 94.33%/94.44%。在图中对照 WADS 的 Ours 与 w/o probabilistic labels 两行；w/o 2D BEV features 是另一套消融，不是单独关掉权重。离线 ASDR+C-GLP 的 F1 为 98.61%/98.01%，两者均高于完整组，但单帧用时为 217/927 ms，而学生为 17/59 ms。[Tables 2–3，pp.11–12；Sec. 5.2.2，p.13]

证据边界： 主表是指定测试样本，不是 Table 6 的五种子均值。没有分别测得软目标、课程和加权的独立增益，也没有证明 0.5 权重下限或三分阶段最优。测试人工标注不参考离线输出，但阈值后的 F1 不是软标签校准检验。Fig. 9/Table 7 仍有树叶与建筑误删；Boreas 无逐点真值，不能用下游 VGICP 弥补校准证据缺口。[Secs. 5.1、5.4.2、5.6；PDF pp.9–10、16–18]
