专题问题：距离补偿能保证不误删远处结构吗？

已有论文专题回看，不是新论文，也不是新的阅读阶段。回看日期：2026-11-09。对象为 Akhil Kurup、Jeremy Bos 的 DSOR（2021）。本次重新取得并阅读全文与全部图表：固定 arXiv:2109.07078v2，7页，页面标记2021-10-30；未以预印本冒充正式出版版，没有运行滤波或复现实验。原初读保持不变。

本次新增理解把“按距离删除了多少点”“实际雪点被删除了多少”“删除集合中有多少真雪点”分开看。距离补偿回应采样稀疏，不代表对所有真实稀疏结构有保真保证；同一张距离图，相对 SOR 与相对 DROR 得出的比较也不同。

1. 补偿的是判别阈值，不是给物体身份加保证

作者表述DSOR 先统计每点 k 近邻的平均距离，再计算其全局均值 μ 和标准差 σ；以 Tg = μ + sσ 形成基础阈值，再按点到传感器的距离 d 调整为 Td = Tg × r × d。k、s、r 是输入参数。作者将此设计解释为应对点间距随距离变化。Sec. IV-A，Eqs. (1)–(2)，Algorithm 1，PDF p.4。

阅读者归纳这里的动态指逐点距离阈值，不是自动识别天气、在线学出参数或识别物体类别。本文没有给出跨不同硬件保持参数不变的系统对照，不能从公式直接读出“免调参”或“跨传感器通用”。这属于对证据范围的限定，不是作者证明了方法不能跨传感器。

原文差异仍保留Sec. IV-A 在式(2)后的正文将 mean distance < Td 写作删除 outliers；Algorithm 1 lines 11–12 却在相同条件下将点作为 inliers 保留。两处方向相反，本次核读确认差异仍在，不替作者修正，不据此声称已经复现。该差异也不改变下文按原文报告值阅读实验的身份。

2. 同一距离补偿，相对哪个基线？

作者表述定量与定性结果基于100帧落雪点云的平均；计时部分说明使用64线、每帧约20万点。Precision / Recall 的去雪结果与按距离删点比例分别呈现，不是一个指标。Sec. V开头与V-B–D，PDF pp.5–6。

直接观察横轴为距离 Range（m），纵轴为被过滤点的百分比（Percent Filtered），并不是雪点正确率。(a)蓝色为SOR，(b)蓝色为DROR；两图红色都是DSOR。约20m以外，DSOR相对SOR删除明显更少，相对DROR却有些距离段删除更多。作者在V-B明确指出后一现象可能降低远处Precision；不能把“比SOR保留更多”改写成“比所有方法都保留更多”。柱子的高度本身不告诉我们所删点是真雪还是环境结构。

作者表述Sec. V-C进一步报告20m以外的树梢、杆与悬空电线被滤掉：这些特征稀疏，冬季可能只返回少量点。作者另提到去除noisy measurements也可能降低Precision，但这是可能解释，不是额外验证的原因。PDF p.6，Sec. V-C。

3. 95.6% Recall 与 65.1% Precision，各自回答什么？

直接观察横轴是方法DROR/DSOR，纵轴为百分比，蓝柱Precision、红柱Recall。图内标注DROR为71.51/91.89，DSOR为65.07/95.60；Sec.V-C正文分别按一位小数写71.5/91.9与65.1/95.6。本页计算采用正文的舍入数值，未将图与正文的显示精度混成矛盾。误差棒存在，但图注及本页所核正文没有明确说明它们的统计定义，不擅称置信区间。

阅读者的分母展开为解释本文“去除雪”的Precision/Recall，以下统一把真雪点视为正类、把“判为雪并删除”视为预测正类。令TP为正确删除的雪点、FP为误删环境点、FN为遗漏雪点、TN为保留环境点：

Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
环境点误删率 = FP / (FP + TN)

阅读者分析因此，65.1%的Precision对应被判雪删除的集合中，约34.9%不属于真雪（以正文指标定义及其报告/平均口径理解）。它不是“全部环境点被删掉34.9%”；后者的分母是FP+TN，需要环境点总数或相应分距离混淆统计。这里没有把100帧平均分数冒充汇总所有点后重新算出的总体比例，也不能由平均Precision/Recall唯一还原每帧计数。

阅读者分析同样，95.6%的Recall主要回答真雪的去除覆盖程度，不直接给环境结构保留率。DSOR比DROR的Recall增加3.7个百分点，Precision下降6.4个百分点（由正文舍入值相减）；不能只留前一项当“全面更准确”。作者自己明确说，以牺牲环境特征换100%Recall不是目标。Sec. V-C，PDF pp.5–6。

4. 这次回看带走的判断顺序

  1. 先看补偿对象：DSOR改变判别阈值；距离适应性不等于语义保真保证。
  2. 再看对照对象：同一距离曲线，比SOR删得少不代表比DROR删得少。
  3. 最后核对分母：删点比例、雪点Recall、删除集合Precision、环境点误删率不能互相替代。

阅读者归纳这是对本文评测证据的重新组织与分母解释，不是论文新增实验、已验证下游收益、传感器泛化结论或用户未发表的研究方案。未取得分距离混淆计数的部分继续留空。
