原文、版本与专题边界

本页是已有论文专题回看，不是新论文，也不是论文修订报告。原论文 Unsupervised Snowy-Weather Point Cloud Denoising via Two-Stage Filter-Network Collaboration，Wenfeng Leng、Yonghui Huang、Xi Zhang、Chuan Hu，IEEE Transactions on Geoscience and Remote Sensing，2026，vol.64，article 5701715。DOI 10.1109/TGRS.2026.3687212；出版日期2026-04-27，当前版本日期2026-05-05。

本轮重新阅读保留的出版方正式版15页PDF，并实际查看图1–13、表I–VIII；同时核对IEEE一手元数据。没有运行作者代码或复现实验。本页只集中核对DMROR，不再次展开网络写作/代码精读。领域内分类理由：原任务是雪天LiDAR逐点去噪，直接报告WADS和CADC结果；不是因方法名称或是否有网络而分类。

先分开：观测、代理估计与经验标定

原文概括DMROR并非从毫无依据的参数起步：作者以雪强相关的环境点间距变化为动机，借用低强度、近距离和低高度先验估计雪噪比例，再据此缩放搜索半径。但具体指数函数及系数仍包含设计选择和经验拟合。本文没有把该函数推导成唯一的物理定律。[Sec.III-B，PDF p.5]

  1. 观测层：用有标签数据描述不同噪声比例下，正常环境点的KNN距离如何随深度变化。
  2. 推理层：用阈值筛出的候选点比例估计N；运行时不直接读取Fig.4所用的GT噪声比例。
  3. 标定层：视觉比较各帧去噪结果选b，再拟合N到b的参数。
  4. 验证层：用WADS标签衡量结果，在CADC上主要做定性比较。标签用于评价，与是否用于梯度训练是不同问题。

Figure 4提供了什么依据？

作者表述与图注横轴是深度Depth(m)，纵轴是平均KNN距离(m)，K=5。蓝、绿、橙分别表示噪声比例10%、20%、30%；每个条件选择五帧。图注明确：比例由ground-truth labels计算，计算间距时只保留去掉噪声后的环境点。作者据此指出：距离—密度关系随雪强变化，且曲线呈非线性。[Fig.4及Sec.III-B，p.5]

直接观察图中20%绿线在远处增长明显快于10%和30%组。至少这幅选帧图不能支持“噪声比例越大，所有距离的间距都越大”的单调结论。正文未交代这些帧是否匹配场景几何、目标构成和遮挡，图中也没有置信区间。

阅读者归纳它支持把雪强作为需考虑的条件，却不足以单独确定唯一函数形式或证明变化完全由降雪造成。不能把这个观察直接叫作已验证的跨场景因果定律。

部署使用的N，和图中的GT比例不是一回事

原文概括先选候选集合K1：强度i低于imax、距离d低于dmax、高度z在[zmin,zmax]内。估计N=|K1|/|全部点|。随后按半径邻域内点数小于k得到K2，最终噪声是K1∩K2，不是仅凭N或强度就删除。[Sec.III-B，Eqs.(1)–(3)，p.5；Algorithm1，p.7]

b = a₀ exp(a₁N² + a₂N)
R(d,N) = max(d,dmin) · a · b

a按作者定义关联水平角分辨率；dmin为近距离下限。N是先验筛选产生的代理量，不是已校准的真实降雪强度测量。若正常点也落进候选区域，N同样会改变。原文并未给出估计N相对于真实噪声比例的逐帧误差分布。

阅读者公式展开固定一帧的N时，b为常数；d≥dmin后R对d是线性的，d<dmin则为常数。指数非线性在N维度。作者用“非线性距离—密度关系”说明动机，不意味着Eq.(3)逐点复现了Fig.4各条弯曲曲线。这个判断只来自原式展开，不是代码运行结果。

Table II：视觉选择b，再拟合系数

作者表述Sec.III-B先随机抽取不同N的雪天点云，对每帧通过视觉比较去噪结果选合适b，形成多组(N,b)，再用最小二乘求a₀、a₁、a₂。Sec.IV-A另说明通过不带语义标签的可视化获得参数。这里不是把Fig.4的GT—KNN曲线直接回归成半径公式。[p.5；Sec.IV-A，pp.8–9；TableII，p.9]

直接观察WADS与CADC的zmin分别−1.5/−1.2m，zmax为4.2/5m，dmax为14/17m，dmin为6/5m；a₀为0.83/0.82，a₁为14.2/11，a₂均−7，a均1，k均5。两组结果使用各自的参数，不是固定WADS参数直接迁移到CADC。

结论边界论文描述的是“有可解释先验的经验标定”，不是没有选择过程的自动推导。未完整报告视觉选择标准、帧数和一致性，不能独立量化人工选择的不确定性；也不能据此反向断言作者使用测试真值选参。支持动机的GT统计、无语义标签视觉标定、最终有标签评测，应分别记录。

Figure 12：局部稳定，不等于无需标定

作者表述手动阈值组含imax、zmin、zmax、dmax、dmin；拟合组含a₀、a₁、a₂；固定a、k不在敏感性测试中。以默认值为中心扰动±5%、±10%、±15%，imax四舍五入为整数，其他浮点值直接变动。[Sec.IV-F，pp.12–13；Fig.12，p.13]

原文数值与边界作者报告手动组86.97%–88.05%、拟合组87.62%–88.05%，默认88.06%。这是围绕已选配置的局部敏感性，未测试任意初值、所有参数组合或跨传感器不重拟合。作者在Sec.IV-F仍明确：传感器/数据集设置显著变化时重新估计拟合参数。

图沿用作者“mIoU”标记；原文Eq.(18)写为TP/(TP+FP+FN)，本专题不擅自把它改解释为两类IoU的算术平均。Fig.12没有独立拆解每个先验的必要性，不能拿整体稳定性证明每一阈值都是必需的。

本次新增理解与未解决的边界

本次不是再重复“DMROR能造伪标签”，而是补齐三个容易混淆的层次：GT描述性观察≠部署N估计；视觉选b≠从观测曲线直接推导；局部扰动稳定≠跨传感器免标定。

作者还明确承认覆雪植被的弱强度、局部稀疏和不规则几何与雪点重叠，导致正常点误删。时序一致性、邻域强度方差只是其未来改进方向，不能写成已经实现并验证的纠错模块。[Sec.IV-G，Fig.13，p.13]
