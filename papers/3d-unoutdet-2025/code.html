03 · SSR：从 9 个邻域强度到一个伪标签

[代码] 对于第 n 个查询点，SSR 先收集 9 个邻居的强度，对这一行做频域变换，再把得到的 9 维复数向量压成一个标量。这个标量达到或超过阈值就标为非雪，否则标为雪。

设计动机

[论文·设计动机] 作者结合雪点相对低强度的观察与 LiSnowNet 的频域稀疏性思路，希望在没有人工逐点标注时生成监督信号；邻域强度乘距离平方被描述为基于光强反平方规律的可选稳定化处理（III-A、Algorithm 1，PDF 第 3 页）。作者把 FFT 后的 L2 范数用作稀疏性度量；这是论文解释，代码是否等价于显式稀疏计数需另看运算。

04 · NH 卷积：在邻居序列上做加权收缩

[代码] 一次 NH 卷积可以理解为“把每个点的邻居特征排成一小张表，再用共享权重把这张表压成新特征”。所有点都保留在输出中；图上标出的 3×3 表示由 K=3 得到 9 个邻域位置，实际运算不要求点落在规则图像的 3×3 像素格上。

设计动机

[论文·设计动机] 作者保持此前 3D-OutDet 的结构，理由是其轻量、鲁棒且计算开销低；本篇只保留两层 NH 卷积与一条残差连接（III-B，PDF 第 4 页左栏）。NH 运算的更完整设计推导被本篇转引到前作，不能由本篇替作者补出全部选择依据。

  53  
  54      def forward(self, data, dist, ind):
  55          self.data = torch.from_numpy(self.data).to(data.device)
  56          intensity = self.data[:, 3]
  57          sq_dist = torch.sum(self.data[:, :3] * self.data[:, :3], dim=1)
  58          intensity /= sq_dist
  59          # intensity *= 255.0
  60          # get neighbours intensity
  61          ki = intensity[ind[:, :5]]
  62          standard_ki = ki * dist[:, :5] * dist[:, :5]
  63          fft = torch.fft.fft(standard_ki, dim=1, norm='backward')
  64          fft_norm = fft.norm(p=2, dim=1)
  65          sup = torch.where(fft_norm >= self.th, 0, 1)
  66          return sup.reshape(-1)
  1. [代码] sq_dist = x²+y²+z² 是每点到传感器原点的平方射程；intensity /= sq_dist 先对原始强度做除法。它与 WADS 恢复标准化强度的过程不同。
  2. [代码] 随后用 ind[:,:5] 收集 5 个邻居，并乘 dist[:,:5]²；这里 dist 仍来自 reader 的近邻距离加一。FFT 和 L2 均沿这 5 个邻域位置计算。
  3. [代码] 训练脚本设阈值 1e-9，与 WADS 的 2.5 不同；学习率也由 1e-2 改为 1e-5。scripts/train_CADC_unsupervised.py · L62–80、scripts/train_CADC_unsupervised.py · L130–148。

[代码] CADC Dataset 的读入辅助方法创建占位零标签，随后删除 label 字段并返回文件路径；训练和验证指标在这里对伪标签计算，不能视作人工去雪 IoU。见 dataset/unsupervised/_cadc_dataset.py · L46–55、scripts/train_CADC_unsupervised.py · L154–163。论文人工标注 CADC 评估及补充材料的机器标签生成是另外的评估流程，本报告不把这些标签混进该训练支路。
