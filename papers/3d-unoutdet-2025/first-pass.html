3D-UnOutDet: A Fast and Efficient Unsupervised Snow Removal Algorithm for 3D LiDAR Point Clouds

01 · 论文一句话在做什么

概括作者面向雪天 3D LiDAR 点云中的落雪噪声，提出 3D-UnOutDet：先用 Statistical Snow Remover（SSR）依据邻域强度生成伪标签，再训练保留原有结构的 3D-OutDet 后端，在不使用人工训练标签的条件下去雪，并考察其对语义分割和车辆检测的帮助。 （Abstract；Sec. I；Sec. III）

02 · Research Problem

问题层次原文故事线
具体问题

概括对真实扫描点云中的落雪点进行 snow / non-snow 二分类并删除落雪噪声。 （Sec. I；Sec. V-B）

发生场景

概括自动驾驶车辆在降雪环境中使用 3D LiDAR；实验覆盖 WADS 与 CADC 两个真实采集数据集。 （Sec. I；Sec. IV）

为什么重要

作者表述雪花降低传感器读数质量，进而损害场景语义分割、目标检测等下游感知；训练高性能监督模型又需要昂贵的逐点标注。 （Sec. I）

最终后果

概括作者将噪声导致的下游性能下降，以及域偏移导致已标注数据的效用下降，作为发展无监督去雪方案的动机。 （Sec. I）

03 · Existing Methods & Gap

概括下表只整理本文作者对已有工作的描述，未独立评价被引论文。 （Sec. I–II）

已有方法原本如何处理作者指出的不足及影响
SOR / ROR / DSOR / DROR / LIOR 等统计滤波通过几何邻域、距离或强度等规则识别离群点。无需人工标签，但计算昂贵、精度不足；本文认为传统统计方案的顺序计算限制效率。（Sec. I；II-B）
监督深度网络，如 SalsaNext、Cylinder3D、PolarNet、3D-OutDet把去雪建模为逐点分割。高性能依赖昂贵的逐点标签；跨数据集或真实部署的域偏移可使性能变差。（Sec. I；II-A）
LiSnowNet / SLiDE / SMEDen、SSEDen分别利用变换稀疏性、重建难度、多回波或代表点搜索。作者认为点云无监督去雪研究仍少，与监督方法之间仍存在性能差距；并非本文逐一证明上述机制均无效。（Sec. I；II-B；Fig. 1）

概括统一 gap：作者寻求无需人工训练标注、计算与内存成本低，同时缩小无监督与监督精度差距的点云去雪方法。 （Sec. I；Fig. 1）

04 · Core Observation / Insight

观察 / 假设原文依据如何引出算法
同距离下，雪点通常比非雪点强度低。作者引述 LIOR 的发现。（Sec. III-A，p. 3）SSR 使用 intensity；并可选择距离平方校正。
路面等非雪点也可能低强度，因此单点强度并不充分。作者表示在可用雪天点云中也观察到路面及靠近雪粒子区域的低强度现象。（Sec. III-A）作者假设非雪点多数邻居也为非雪点、强度较高，因此聚合邻域强度。
加性噪声污染的信号在 FFT 变换下比干净信号更不稀疏。作者沿用 LiSnowNet 的观点，并以 FFT 输出的 L2 范数构造分数。（Sec. II-B；III-A）SSR 对邻域强度做 FFT、求 L2 范数并阈值化，产生初始雪点判断。

作者表述上述“稀疏性”解释与非雪邻域假设均按作者身份保留；论文未在设计前提供独立的统计验证图。作者随后让网络从 SSR 的初始判断学习更具描述性的特征，并扩展到剩余潜在雪点。 （Sec. III-A；Sec. I 方法概述；Sec. VI）

05 · Method：只看宏观逻辑

  1. 概括输入带坐标与 intensity 的无标签点云，计算 kNN 的索引和距离；这些邻域信息由 SSR 与网络后端共享。 （Sec. III；Fig. 2，pp. 3–4）

  2. 概括SSR 收集邻域强度，可选做距离平方校正，再计算 FFT 输出的 L2 范数并与阈值比较，得到逐点伪标签；目的在于结合作者所述的强度与稀疏性线索。 （Sec. III-A；Algorithm 1）

  3. 概括3D-OutDet 后端接收原始点及邻域信息，沿用两层 NeighborHood Convolution 和一个残差连接，使用 SSR 标签计算交叉熵与 Lovasz-Softmax 损失。 （Sec. III-B；Fig. 2）

  4. 概括训练后由网络输出 snow / non-snow 判断并去除雪点；作者报告推理耗时与原监督 3D-OutDet 相同，SSR 主要提供训练监督。 （Sec. III-B；Table I）

概括核心变化的位置：保留 3D-OutDet 网络结构，把训练所需的人工逐点标签换成 SSR 生成的初始判断；作者同时提出 SSR 本身。网络中不插入 LiSnowNet 式 FFT / DWT 模块。 （Sec. II-B；III-B）

结果 1 · WADS 上缩小无监督精度差距

直接观察实验结果：3D-UnOutDet mIoU 为 89.04%，LiSnowNet-L2 为 82.71%，差 6.33 个百分点；SSR 为 81.76%。监督 3D-OutDet 和 PolarNet 分别为 90.00%、90.16%。 （Table I；Sec. V-B，pp. 4–5）

作者表述作者据此得出的结论：作者据此认为其无监督模型超过所比较无监督方法，并达到接近监督方法的表现。 （Table I；Sec. V-B，pp. 4–5）

结果 2 · 轻量网络与总耗时必须分开读

直接观察实验结果：3D-UnOutDet 的 runtime / preprocessing / postprocessing 为 3 / 78 / 0.7 ms，表中 total 为 82 ms；参数 11.02 K、运算 2.67 GMAC。LiSnowNet-L2 总耗时 131 ms；SSR 45 ms；SSEDen 58 ms。 （Table I；Sec. III-B；VII）

作者表述作者据此得出的结论：作者强调网络轻量、计算成本低，并在讨论中明确最近邻计算是瓶颈。其“总执行时间最快”的概括不能解释为 Table I 每个无监督方法都慢于 82 ms；表中 SSR 与 SSEDen 总时间更短。 （Table I；Sec. III-B；VII）

结果 3 · 下游任务在文中训练设置下受益

直接观察实验结果：WADS 语义分割：SalsaNext 20.11→22.31，Cylinder3D 22.39→27.62，PolarNet 23.83→26.80 mIoU。CADC 汽车检测：PointPillars 53.73→55.77，CenterPoint 51.63→52.52，SECOND 57.02→58.66（Car mAP R40 Avg）。 （Tables II–III；Sec. V-B–C，pp. 5–6）

作者表述作者据此得出的结论：作者认为去雪可改善下游模型表现而无需改变模型结构。语义模型用去雪后数据训练；检测采用雪天与去雪点云增强训练数据，不能省略这一训练条件。 （Tables II–III；Sec. V-B–C，pp. 5–6）

结果 4 · CADC 人工与机器标签上分别评估

直接观察实验结果：200 帧人工标注：3D-UnOutDet 87.39%，LiSnowNet-L2 74.62% mIoU，差 12.77 个百分点。2687 帧机器标注：分别为 75.13%、64.51%。 （Table IV；Sec. IV；V-A、V-C；VII）

作者表述作者据此得出的结论：作者认为在传感器线数和雪密度不同的 CADC 上仍优于比较模型；正文另外报告了 CADC 专用配置，不能把此处写成固定参数的零样本迁移。 （Table IV；Sec. IV；V-A、V-C；VII）

结果 5 · 伪标签与后端消融

直接观察实验结果：完整 SSR / 去掉 FFT / 以距离替代强度的 mIoU 为 81.76 / 79.74 / 57.85%；SSR 标签 / LIOR 标签 / 随机标签训练的网络为 89.04 / 75.11 / 15.94%；PointNet、RandLA-Net 后端为 64.27%、67.59%。 （Sec. VI；Table V，p. 7）

作者表述作者据此得出的结论：作者认为较高质量初始标签有助学习，FFT 与强度信息对 SSR 有帮助，保留 3D-OutDet 后端在这些替换中效果最好；这些是该消融设置下的解释。 （Sec. VI；Table V，p. 7）

作者表述作者补充材料还说明，CADC 两个人工标注序列交叉训练两个监督模型，平均预测概率后标注其余 30 个测试序列。此说明仅补充机器标签来源。 （作者补充材料 S6）

08 · Limitations

作者明确承认的 limitation

  • 作者表述SSR 依赖雪的低强度与稀疏性特点，作者认为用于雾或 dirt 污染点云时不会具有同等效力。 （Sec. VII，p. 7）

  • 作者表述执行时间主要花在最近邻计算，这是瓶颈。 （Sec. VII，p. 7）

  • 作者表述从 WADS 转至 CADC 仍需要调整配置，例如 k；作者将其与 64 线和 32 线分辨率差异联系起来。 （Sec. VII；Sec. V-A）

  • 作者表述点云稀疏程度/质量与下游增益之间的关系还需要进一步实验，超出本文范围。 （Sec. VII）

图表中直接可见、作者未统一称为 limitation 的现象

  • 直接观察3D-UnOutDet Recall 为 92.68%，低于 LiSnowNet-L2 的 98.22%；其 Precision 则为 95.77%，高于后者 83.94%。作者也在讨论中指出二者侧重不同。 （Table I；Sec. VII）

  • 直接观察下游总体 mIoU 上升并不表示每类都上升：SalsaNext 的 road IoU 从 64.37 降至 63.15，fence 从 23.85 降至 18.91。 （Table II，p. 5）

10 · 论文逻辑链

  1. 概括现实问题：雪粒子污染 LiDAR 点云并降低下游感知质量。 （Sec. I）

  2. 概括现有方法：统计规则无需标签，监督网络精度较高。 （Sec. I–II）

  3. 概括不足：统计计算与精度有限，监督标注昂贵且受域偏移影响。 （Sec. I）

  4. 概括观察：雪点低强度及邻域变换特性可用于初始识别，但路面也可能低强度。 （Sec. III-A）

  5. 概括解决思想：把统计初始判断转为网络训练的伪标签。 （Sec. I；III）

  6. 概括方法：SSR 与不改结构的 3D-OutDet 共享 kNN 信息。 （Fig. 2；Sec. III）

  7. 概括实验：WADS/CADC 去雪、下游分割/检测及模块消融。 （Sec. IV–VI）

  8. 概括结论：作者认为该组合缩小无监督精度差距，且能在文中设置下改善下游任务。 （Sec. VIII）

11 · 第一遍阅读结束后，我应该记住的东西

  1. 概括问题是从真实雪天 LiDAR 点云中识别并删除落雪点，减少对后续感知的干扰。 （Sec. I）

  2. 概括核心 gap 是无需人工训练标注的准确、低成本去雪，尤其是无监督与监督方法的精度差距。 （Sec. I–II）

  3. 概括关键 insight 是用邻域强度与作者所述 FFT 稀疏性线索做初始识别；非雪邻居假设保留为作者假设。 （Sec. III-A）

  4. 概括核心变化是 SSR 生成监督信号，3D-OutDet 网络结构保留。 （Sec. III-B）

  5. 直接观察WADS 表中 mIoU 89.04%，高于 LiSnowNet-L2 的 82.71%；3 ms 仅为网络 runtime，总耗时为 82 ms。 （Table I）
