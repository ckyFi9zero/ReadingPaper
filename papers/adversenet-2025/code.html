02 · 从文件中的点，到两套柱坐标索引

[代码] 输入文件的每行包含 xyz、强度和标签。送入网络的不是这五个数原样拼接：标签单独存放，点特征变成 9 维；同一个点还携带一份用于体素归并的整数索引，以及一份保留小数的位置用于最终回查。

设计动机

[论文·设计动机] 常规体素表示的计算与存储随三维分辨率乘积增长，单平面又难保留三维细节；作者用三平面补充结构，并用柱坐标适应点云近密远疏的分布（II-A，PDF 第 3 页右栏）。9 维具体拼接和边界裁剪的逐项动机在论文中未展开。

[代码] DENSE 转换脚本从 HDF5 取第一回波 xyz、intensity、label，去掉无效行并将强度转为 255 尺度；训练 Dataset 读文本后再除以 255。SnowyKITTI 的转换处理 binary 点和语义标签，并统一成文本。来源：formats/DENSE/hdf5totxt.py · L24–34、formats/DENSE/cnnfilter.py · L4–9、formats/SnowyKITTI/binlabeltotxt+filter.py · L25–40、dataloader/dataset.py · L66–77。

03 · 逐点 MLP 与体素最大聚合

[代码] 多个点可能落入同一个柱坐标体素。先分别编码每个点，再对同体素所有点的每个通道取最大值，就把变长点集变成一个占用体素的特征。

设计动机

[论文·设计动机] II-A 说明逐点 MLP 与体素内最大聚合用于构建柱坐标体素特征（Eqs. (2)(3)，PDF 第 3 页）。当前材料没有明确比较为什么此处选择 max 而非 mean；不能把存在 scatter_max 本身当作作者的比较证据。

[代码] point_mlp 与 fea_compression 按 9→64→128→256→256 编码，部分层后接 BN/ReLU；同体素聚合之后，再由 Linear(256,32)+ReLU 压缩。配置令 track_running_stats=False，因此不能假设推理使用累积好的 BN running mean/variance。

04 · 空间分组池化：三张平面怎么形成

[代码] 生成 ρ–θ 平面时，每条固定 ρ、θ 的高度柱不直接压成一个最大值。代码先保留 16 组高度摘要，将它们沿通道排在一起，再学习如何压回 32 通道。另两个平面对其各自被压缩的轴做同类操作。

设计动机

[论文·设计动机] 直接沿整条轴做 max pooling 会丢失细粒度几何；空间分组池化先在 K 组内分别汇聚，再拼接与 MLP 映射，以保存更多结构（II-A 末段，PDF 第 3–4 页，Eq. (4)）。这是采用分组的明确动机，不代表本次已验证保留了多少几何信息。

5.2 RDB、SCM、FAM、AFF 分别做什么

设计动机

[推断·设计动机] 以下四个内部单元的直观解释来自实际 concat、逐元素乘与残差连接。论文只给出网络借鉴及缩减的总体说明，没有为每个单元提供独立图、公式或逐项设计论证；不将这些解释写成作者已验证的机制。

原仓库摘录 · RDB：卷积输出逐层拼接，末端压缩再残差相加
model/Network_Stage1.py · L33–61
  33  class RDB_Conv(nn.Module):

  35          super(RDB_Conv, self).__init__()

  43  class RDBlock(nn.Module):
  44      def __init__(self, in_channel, out_channel, nConvLayers=3):
  45          super(RDBlock, self).__init__()
  46          G0 = in_channel
  47          G = in_channel
  48          C = nConvLayers
  49  
  50          self.conv0 = RDB_Conv(G0 , G)
  51          self.conv1 = RDB_Conv(G0 + 1 * G , G)
  52          self.conv2 = RDB_Conv(G0 + 2 * G , G)

  54          self.LFF = BasicConv(in_channel=G0 + C * G, out_channel=out_channel, kernel_size=1, stride=1, relu=False)
  55  
  56      def forward(self, x):

  58          out = self.conv1(out)
  59          out = self.conv2(out)
  60          out = self.LFF(out) + x

[代码] RDB_Conv 每次把输入与新生成的 G 通道 concat。一个 RDBlock 内三次增长，从 C→2C→3C→4C，再 1×1 压回 C，与原输入相加。EBlock 和 DBlock 都串三个 RDBlock；传入的 num_res 在这两个类里没有控制实际层数。model/Network_Stage1.py · L63–88。

[推断·设计动机] RDB 的连接让后续卷积同时读取此前特征和新增特征；末端残差保留原特征路径。依据是上面明确的 concat 与 +x，不能由此声称该连接在本次数据上独立提升了性能。

原仓库摘录 · SCM 与 FAM：拼接上下文，再乘法结合与残差回加

 103  class SCM(nn.Module):
 104      def __init__(self, out_plane):
 105          super(SCM, self).__init__()
 106          self.layer1 = BasicConv(32, out_plane// 2, kernel_size=3, stride=1, relu=True)
 107          self.layer2 = BasicConv(out_plane// 2, out_plane-32, kernel_size=1, stride=1, relu=True)
 108          self.conv = BasicConv(out_plane, out_plane, kernel_size=1, stride=1, relu=False)
 109  
 110      def forward(self, x):
 111          out = self.layer1(x)
 112          out = self.layer2(out)
 113          x = torch.cat([x,out], dim=1)
 114          return self.conv(x)

 116  class FAM(nn.Module):
 117      def __init__(self, channel):
 118          super(FAM, self).__init__()
 119          self.merge = BasicConv(channel, channel, kernel_size=3, stride=1, relu=False)
 120  
 121      def forward(self, x1, x2):
 122          x = x1 * x2
 123          out = x1 + self.merge(x)
 124          return out

[代码] SCM 对缩小的原平面做 32→out/2→out−32 两次卷积，与原 32 通道拼成 out，再做 1×1。FAM 接收主支和 SCM 同形状特征，先逐元素相乘，3×3 卷积之后加回主支。

[推断·设计动机] SCM 让后续尺度仍能取得从原平面直接变换的信息；FAM 的乘法使补充分支能调制主支响应。这是对数据流的解释，论文没有给出该乘法相对于直接相加的单独选择依据。

11 · 本阶段已经打通的连接

[理解小结] 输入点先得到整数体素归属与浮点查询位置；9 维点特征经逐点 MLP、体素 max 和空间分组池化形成三张平面。相同编码器逐个处理三平面，天气特定卷积由外部天气 flag 与层评分共同控制，最后按原点位置采样、相加并输出五类 logits。

[关键边界] 自动决定是否扩展某层的天气参数，与自动识别一帧属于什么天气是两件事；这份实现只定位到前者。Stage2 的默认加载配置、三次优化更新、正则缩放及乘零分支的实际执行，都需要与论文示意分别阅读。

[仍未打通] 公开权重是否与当前配置和指标口径完全对应、给定环境是否能直接运行、稀疏池化边界及实际速度尚未执行验证。本报告完成方法与指定源码的静态连接，不宣称复现论文数值。
