一、论文一句话在做什么

概括Removert 先用严格可见性关系保守删除疑似动态点，再逐级降低 range image 分辨率、扩大隐式 query–map 关联窗口，把因位姿/配准误差而误删的静态点逐步恢复。 （Abstract；Introduction；Method overview）

二、Research Problem

作者表述具体问题：从含车辆和行人的城市点云地图中构造静态地图。 （Abstract；Introduction）
作者表述场景：户外 SLAM、先验地图定位、地图维护与更新。 （Abstract；Introduction）
作者表述重要性：静态结构是鲁棒定位和长期地图的基础。 （Abstract；Introduction）
作者表述后果：动态残留造成假结构，错误删除又损害地图完整性。 （Abstract；Introduction）

三、Existing Methods & Gap

方法类别原本怎么解决作者指出的不足及影响
时序/占据更新连续融合可见性并更新点状态常假设位姿/配准正确，关联误差会误删静态点。
固定角窗可见性在固定范围寻找 scan–map 对应固定窗口不能表达不同程度运动误差。
语义分割按动态类别删除点依赖监督标签，受未知类别和人工标注误差影响。
概括作者认为真正缺少的是：依赖监督标签，受未知类别和人工标注误差影响。 （Introduction；Related Work）

四、Core Observation / Insight

  • 作者表述静态地图构造与动态物体删除相互依赖，且 query–map 关联会因位姿误差变得模糊。 （Introduction；Method）
  • 作者表述作者因此采取“先严格 remove，再逐级 revert”：细分辨率保守确认静态，粗分辨率扩大关联窗口来补偿误差。 （Introduction；Method）

五、Method：只看宏观逻辑

概括Input：由 LiDAR odometry/SLAM 提供的扫描、位姿与聚合地图。 （Method；framework figure）
概括在多帧上构造 map/query range images，通过可见性差异执行多轮 removal。 （Method；framework figure）
概括把被删点保留在候选集合，逐级降低 range image 分辨率，扩大像素关联窗口。 （Method；framework figure）
概括按每级可见性把可能误删的静态点逐步 revert 回地图。 （Method；framework figure）
概括Output：静态地图及可派生的逐点动态标签。 （Method；framework figure）
概括相比已有方法，真正发生变化的核心位置是：把被删点保留在候选集合，逐级降低 range image 分辨率，扩大像素关联窗口。 （Method）

十、论文逻辑链

概括现实问题：动态物体污染静态地图，误删也会破坏地图。
概括现有方法：可见性/占据更新、固定窗口或语义删除。
概括不足：配准误差使 query–map 对应不可靠。
概括观察：关联窗口可用 range image 分辨率逐级放宽。
概括思想：先高置信删除，再多级恢复。
概括方法：多轮 remove + multiresolution revert。
概括验证：KITTI/SemanticKITTI、MulRan、迭代统计与可视化。
概括结论：作者认为能去除动态点并恢复多数误删静态点。

十一、第一遍阅读结束后，我应该记住的东西

  1. 概括解决动态城市点云中的静态地图构造。
  2. 概括核心 gap 是 scan–map 关联依赖不完美位姿，固定窗口会误删。
  3. 概括最关键 insight 是 range-image 分辨率可以充当关联置信尺度。
  4. 概括核心变化是“先删除、后多分辨率恢复”。
  5. 概括最重要结果是 revert 迭代中 FN 显著下降而 FP 增长较小。
